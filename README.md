# 么九麻雀（やおちゅうまーじゃん）

**么九牌だけで遊ぶ、1人＋CPU3人のオリジナル四人麻雀。** ブラウザだけで動きます。登録・サーバー・外部ライブラリ不要です。

## 遊ぶ方法

- **GitHub Pages**：このフォルダーの中身をリポジトリのルートにアップロード → GitHub の **Settings → Pages** → **Build and deployment** にて **Deploy from a branch** を選択 → `main` / `/(root)` を選択して保存。数分後に発行された URL で遊べます。
- **ローカル**：ブラウザの ES Modules を使うためファイルの直開きではなく、`python3 -m http.server 8000` などで配信し、`http://localhost:8000` を開いてください。Node.js があれば `npm test` でルールのテストができます。
- **Cloudflare Pages**：GitHub リポジトリを接続し、フレームワークは「None」、ビルドコマンドは空欄、出力ディレクトリは `/`（またはプロジェクトルートに相当する設定）で静的配信できます。

## ルール

| 仕様 | 内容 |
| --- | --- |
| 参加者 | 人間1名、CPU3名 |
| 牌 | 萬子・筒子・索子の1と9、東南西北白發中。13種を**各12枚**、合計156枚 |
| 進行 | 東1〜4局の東風戦。親のアガリ・親テンパイ流局・8カン流れで連荘。通常流局または親の連荘で本場が増える |
| 配牌・山 | 各13枚を配牌、残り104枚（通常山80枚、嶺上牌8枚、ドラ表示牌8枚、裏ドラ表示牌8枚） |
| アガリ | 刻子4組＋雀頭、七対子（異なる7対子）、国士無双 |
| 宣言 | リーチ・ポン・ロン・ツモ・暗槓・大明槓・加槓。チーは不可 |
| 点数 | 翻・符で点数計算。13〜25翻は数え役満、26〜38翻はダブル役満、39〜51翻はトリプル役満（ドラ・裏ドラを含む）。既存役満の複合も倍付け |
| 役 | 混老頭、対々和、七対子、役牌、三暗刻、小三元、混一色、三色同刻、立直、一発、門前ツモなど。国士無双、四暗刻、大三元、字一色、清老頭、四喜和は役満 |
| ドラ | ドラ・裏ドラ・カンドラ・カン裏ドラあり（赤ドラなし）。立直で裏ドラ公開、役満にはドラ加算なし |
| フリテン | 捨て牌フリテン・同巡フリテン・リーチ後ロン見逃しに対応 |
| 同時ロン | ダブロン・トリロン可。放銃者は各アガリ者へ独立して支払う。親を含めば連荘。供託は放銃者から最も近いアガリ者がまとめて受け取る |
| ポン | 人間に最優先で選択機会を提示。ポン直後の同種牌の打牌（食い替え）は禁止 |
| 流局 | テンパイ／ノーテンで合計3,000点を精算。全員テンパイ・全員ノーテン時は移動なし |
| 本場 | ロンは1本場につき+300点を放銃者が支払う。ツモは各家が1本場につき+100点を支払う。子のアガリで本場が0に戻る |
| 保存 | 同じブラウザの localStorage に進行状況を自動保存。再読み込みで再開 |

通常の四人麻雀には存在しない「同じ牌が12枚ある」条件を前提にした**独自ルール**です。正式な日本麻雀のルールと完全には一致しません。例えば役満は倍付けを採用しますが、ダブル役満は別設定せず、天和・地和・海底などの偶然役はありません。CPUは実際の他家の手牌を参照せず、手牌の必要枚数と公開された捨て牌・副露で打牌を選びます。

## ファイル

- `index.html`：画面の構成
- `style.css`：デスクトップとスマホの表示
- `engine.js`：牌、アガリ判定、点数計算、向聴数相当の計算
- `app.js`：画面表示、CPUの判断、対局進行、ブラウザ保存
- `tests/engine.test.js`：ルールの自動テスト

自由にフォーク・改造して利用できます。

ドラの巡回：萬子・筒子・索子は1↔9、風牌は東→南→西→北→東、三元牌は白→發→中→白。表示牌の重複はそれぞれ加算します。カン後に新たなドラ表示牌を追加し、立直アガリ時には対応する裏ドラ表示牌を公開します。役満にはドラを加算しません。

## 2026-11-01 親の連荘・本場・複数数え役満

- 親がアガると親番が続き、1本場加算。東4局も親が続く限り終わりません。
- 通常流局では親がテンパイなら連荘、親がノーテンなら次局へ。どちらも本場を1つ加算。8カン流れは連荘＋1本場（ノーテン精算なし）。
- 子のアガリでは次局へ進み本場は0へ。ロンの本場積み棒は放銃者が300点/本場、ツモでは他家が各100点/本場を追加負担します。
- 13〜25翻＝数え役満、26〜38翻＝ダブル役満、39〜51翻＝トリプル役満。以後13翻ごとに1倍増。ドラ・裏ドラも翻数に含めます。既存の役満・複合役満にはドラを追加しません。
- 保存データはv4へ変更。前のバージョンの進行中の局は引き継がず、新しい対局から始めます。

## 2026-11-02 飛び終了・カンドラ後めくり

- **飛び終了**：アガリ・通常流局の精算後に、いずれかのプレイヤーが **0点未満** なら、その局の結果画面から最終順位へ進みます。0点ちょうどは続行します。従来どおり残った供託は最終順位確定時にトップへ加算します。
- **カンドラのタイミング**：暗槓は宣言後すぐ公開（嶺上牌でアガっても新ドラが乗る）。大明槓・加槓は、嶺上ツモ後の打牌がロンされずに成立してから公開（その嶺上開花に新ドラは乗らない）。連続カンが起きた場合は、次の嶺上ツモの直前に未公開のカンドラをめくります。
- 進行中のv4保存対局は、過去に既にめくられたカンドラを維持してv5に移行します。


## 2026-11-02 ダブロン・トリロン・スマホ牌の視認性

- 頭ハネを廃止。1枚の捨て牌への2人のロン（ダブロン）・3人のロン（トリロン）を全員有効にします。複数人の槍槓ロンも同様です。
- 放銃者が各アガリ者にそれぞれのロン点＋本場加算（1人あたり300点/本場）を支払います。複数アガリ者のうち親が含まれれば親続行。供託のリーチ棒は放銃者からツモ順に最も近いアガリ者が受け取ります。
- **飛び判定は全員のアガリ得点の清算後**。ダブロン・トリロンによって持ち点がマイナスになった場合は、全員の手牌・支払額を表示してから最終結果画面に移ります。
- スマホでの識別性改善：筒子は丸の印、索子は竹状の縦線、さらに異なる枠線・淡い背景で識別できます。数字や牌種表記の視認性も上げました。
- v5の対局データはそのまま引き継ぎます。保存中の旧ルールのロン選択画面も処理可能です。

## v1.1.0 操作補助（2026-11-04）

- 手牌下に **鳴き無し** と **自動アガリ** の操作補助を追加。現在は3段階（ON／常時ON／OFF）で、初期状態はOFFです。
- 鳴き無し：他家の捨て牌へのポン・大明槓を自動で見送り、確認画面を出しません。自分で行う暗槓・加槓は制限しません。ロンの権利も失いません。
- 自動アガリ：成立したツモ・ロン（槍槓含む）を自動で実行。ダブロン・トリロンの場合は全員分を従来通り精算します。
- 対局中に切り替え可能。常時ONの設定は次の対局にも引き継がれ、ONは局の終了後に解除されます。進行中のv5対局データはそのまま再開できます。
- 対局ルール、CPU、得点計算の変更はありません。v1.0.0はGitHub Releaseとして保存されています。

## 操作補助の3段階設定（2026-11-04）

- 「鳴き無し」「自動アガリ」は、それぞれ **ON／常時ON／OFF** を選択できます。
- **ON**：今の局だけ有効です。次の局が始まった時点で自動的にOFFに戻ります（親の連荘・本場継続・途中流局も同様）。新しい対局を始めた場合もOFFです。
- **常時ON**：局や対局をまたいで有効です。明示的にOFFまたはONへ変更するまで保持されます。
- **OFF**：機能を使用しません。初期状態はいずれもOFFです。
- どちらの設定も局の途中で変更可能です。ブラウザを再読み込みしただけでは「今の局だけ」のONを解除せず、次局への切り替え時に解除します。
- 旧版のON/OFF設定がブラウザに残っている場合、既存のONは常時ONに対応付け、ユーザーが以前指定した動作を維持します。
- CPUの思考・点数計算・ランキング登録処理に変更はありません。

## ツモ切りの操作補助（2026-11-04）

- **ツモ切りボタン**：自分の手番で引いた牌を、手牌から探さずにそのまま捨てます。手番ではないときやツモ牌がないときは無効です。リーチを宣言する牌を選択している間も使用できません。
- **自動ツモ切り**：これまでの「鳴き無し」「自動アガリ」と同じ **ON／常時ON／OFF** を追加。ONは現在の局だけ、常時ONは次局以降も維持します。初期状態はOFF。
- 自動ツモ切り中はツモ牌が見えてから少し待って打牌します。ただし **ツモアガリ可能な場合は自動で捨てず、手動の「ツモ！」か自動アガリ設定の判断を優先**します。
- 立直後も利用できます。対局や牌効率を評価するCPUの処理、点数計算、ランキングには変更がありません。

## お任せAIモード（2026-11-12）

- 操作補助に「**お任せAI**」を追加。OFF（手動）、ON（現在の局だけ）、常時ON（局・対局をまたいで継続）を選択できます。初期値はOFF。
- AI有効中はプレイヤー席（あなた）のツモ・捨て牌・リーチ・暗槓・加槓・ポン・大明槓・ロン・ツモアガリを、既存CPUの判断基準で操作します。CPUの手牌評価や点数計算は変更しません。ほかの3席のCPUも従来どおり動きます。
- お任せAIは「自動ツモ切り」より優先して、牌効率を評価して捨て牌を選びます。**鳴き無しがONのときは鳴きません**。アガリは自動で宣言します。
- AI中は手動打牌ボタンを無効にし、設定をOFFにするとその場で手動操作に戻せます。局終了後は結果を数秒間表示して自動で次局へ進みます。結果画面の「お任せAIを停止する」でも止められます。東風戦終了や飛び終了で自動進行を止め、勝手に新しい対局を始めません。
- AIの「ON」は次局開始でOFFになり、「常時ON」は設定として保存されます。ページ再読込後も、対局の現在状態に応じて再開します。ランキング用の保存データやゲームの進行データの形式は変更しません。
