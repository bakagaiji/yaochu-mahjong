# 么九麻雀（やおちゅうまーじゃん）

**么九牌だけで遊ぶ、1人＋CPU3人のオリジナル四人麻雀。** ブラウザだけで動きます。登録・サーバー・外部ライブラリ不要です。

## 遊ぶ方法

- **GitHub Pages**：このフォルダーの中身をリポジトリのルートにアップロード → GitHub の **Settings → Pages** → **Build and deployment** にて **Deploy from a branch** を選択 → `main` / `/(root)` を選択して保存。数分後に発行された URL で遊べます。
- **ローカル**：ブラウザの ES Modules を使うためファイルの直開きではなく、`python3 -m http.server 8000` などで配信し、`http://localhost:8000` を開いてください。Node.js があれば `npm test` でルールのテストができます。
- **Cloudflare Pages**：GitHub リポジトリを接続し、フレームワークは「None」、ビルドコマンドは空欄、出力ディレクトリは `/`（またはプロジェクトルートに相当する設定）で静的配信できます。

## ルール

| 仕様 | 内容 |
| --- | --- |
| 参加者 | 人間1名、CPU3名 |
| 牌 | 萬子・筒子・索子の1と9、東南西北白發中。13種を**各12枚**、合計156枚 |
| 進行 | 東1〜4局の東風戦。親は毎局移動。連荘、本場なし |
| 配牌・山 | 各13枚を配牌、残り104枚（通常山96枚、嶺上牌8枚） |
| アガリ | 刻子4組＋雀頭、七対子（異なる7対子）、国士無双 |
| 宣言 | リーチ・ポン・ロン・ツモ・暗槓・大明槓・加槓。チーは不可 |
| 点数 | 翻・符で点数計算、満貫・跳満等の上限、複数役満の複合に対応 |
| 役 | 混老頭、対々和、七対子、役牌、三暗刻、小三元、混一色、三色同刻、立直、一発、門前ツモなど。国士無双、四暗刻、大三元、字一色、清老頭、四喜和は役満 |
| ドラ | ドラ、赤ドラ、裏ドラなし |
| フリテン | 捨て牌フリテン・同巡フリテン・リーチ後ロン見逃しに対応 |
| 同時ロン | 頭ハネ（放銃者から近い順） |
| ポン | 人間に最優先で選択機会を提示。ポン直後の同種牌の打牌（食い替え）は禁止 |
| 流局 | テンパイ／ノーテンで合計3,000点を精算。全員テンパイ・全員ノーテン時は移動なし |
| 保存 | 同じブラウザの localStorage に進行状況を自動保存。再読み込みで再開 |

通常の四人麻雀には存在しない「同じ牌が12枚ある」条件を前提にした**独自ルール**です。正式な日本麻雀のルールと完全には一致しません。例えば役満は倍付けを採用しますが、ダブル役満は別設定せず、天和・地和・海底などの偶然役はありません。CPUは実際の他家の手牌を参照せず、手牌の必要枚数と公開された捨て牌・副露で打牌を選びます。

## ファイル

- `index.html`：画面の構成
- `style.css`：デスクトップとスマホの表示
- `engine.js`：牌、アガリ判定、点数計算、向聴数相当の計算
- `app.js`：画面表示、CPUの判断、対局進行、ブラウザ保存
- `tests/engine.test.js`：ルールの自動テスト

自由にフォーク・改造して利用できます。
